# План внешних ссылок

Составлено 20 октября 2026. Сейчас у dockentra.ie **0 внешних ссылок** (Search Console → Ссылки). Цель — первые 10–15 настоящих ссылок с тематических и ирландских сайтов.

**Правила.** Не покупать ссылки и не обмениваться ими массово — это прямо запрещено правилами Google о спаме. Не называть партнёром никого, с кем нет договорённости: в письмах — «мы открываемся и предлагаем…», а не «наш партнёр». Письма отправляет владелец; Claude готовит тексты и проверяет, появилась ли ссылка.

## 3. Как проверять результат

- Search Console → Ссылки → «Внешние ссылки»: появляются с задержкой в несколько недель.
- Cloudflare Web Analytics → Referrers: переходы с этих сайтов.
- Раз в две недели Claude проверяет каждую полученную ссылку (работает ли, ведёт ли на нужную страницу).
